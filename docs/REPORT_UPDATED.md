# 수행 계획서 (최종본)

## 1. 프로젝트 제목

**망각곡선 기반 한국 대학생 맞춤형 학습 플래너**
*Forgetting Curve-based Study Planner for Korean University Students*

부제: "잊어버리기 전에 알려주는 똑똑한 학습 도우미"

---

## 2. 연구의 목적 및 배경

### 가. 연구의 필요성

대학생은 한 학기에 평균 4~6과목을 동시에 수강하며, 중간고사·기말고사·과제·발표 등 다양한 학습 의무를 병행해야 한다. 이러한 환경에서 **효율적인 학습 시간 관리**와 **체계적인 복습 계획**은 학업 성취도에 결정적 영향을 미친다.

현재 한국 대학생들이 사용하는 학습 관리 도구는 노션(Notion), 구글 캘린더, 에브리타임 등이 주를 이룬다. 그러나 이들은 **단순 기록**에 집중되어 있어, **"이 내용을 언제 다시 복습해야 가장 효율적인지"** 에 대한 과학적 근거를 제시하지 못한다.

1885년 헤르만 에빙하우스(Hermann Ebbinghaus)의 연구에 따르면, 학습된 내용의 약 67%는 24시간 이내에 잊혀진다. 이를 보완하려면 **망각곡선(Forgetting Curve) 이론에 기반한 과학적 복습 시점**을 자동으로 제공하는 도구가 필요하다.

### 나. 연구의 차별성

본 연구는 기존 도구 대비 다음 다섯 가지 측면에서 명확히 차별화된다.

1. **과학적 알고리즘 기반 자동 복습 일정**
   SuperMemo 2(SM-2) 알고리즘을 적용하여 사용자의 자가평가(0~5점)에 따라 다음 복습일·복습 간격·난이도 계수(EaseFactor)를 자동 계산한다.

2. **한국 대학생 시험 일정 특화**
   중간고사·기말고사·자격증 시험 D-Day를 등록하고, "시험 대비 일정 생성" 기능으로 시험일에서 역산하여 복습 일정을 자동 분산 배치한다.

3. **100% 오프라인 동작 + 로컬 데이터 저장**
   클라우드 의존 없이 SQLite 로컬 DB로 동작한다. 개인 학습 데이터가 외부 서버로 전송되지 않아 프라이버시가 보장된다.

4. **데이터 기반 학습 인사이트**
   학습 패턴(요일별·월별), 복습 진행도, 약점 단원(EaseFactor 낮은 순) 등을 자동 분석하여 시각화한다.

5. **데이터 안전성 및 개인화 확장**
   가져오기 시 자동 롤백 백업 기능으로 데이터 유실을 완벽 방지하며, 과목별 커스텀 색상 지정 기능으로 사용자 취향을 반영한다.

6. **학습 환경 통합 도구**
   포모도로 타이머(집중 25분 + 휴식 5분), 월간 캘린더 뷰, 자동 알림, 다크모드 등 학습 환경 전반을 한 도구에서 제공한다.

## 3. 기존 연구

### 가. 학술적 이론 기반

**(1) 에빙하우스 망각곡선 (Ebbinghaus, 1885)**

무의미 음절을 사용한 자기 실험으로 시간 경과에 따른 기억 보존율을 수학적 함수 R = e^(-t/S)로 표현 (R: 기억 보존율, t: 경과 시간, S: 기억 안정성).

**(2) 간격 효과와 분산 학습 (Cepeda et al., 2006)**

254개 연구 메타분석으로 분산 학습이 집중 학습보다 10~30% 더 나은 기억 보존율을 보임을 확인.

**(3) 학습 전략 효과성 (Dunlosky et al., 2013)**

분산 학습(distributed practice)과 인출 연습(retrieval practice)을 가장 효과적인 학습 전략 1·2위로 평가.

### 나. 기존 학습 도구 분석

| 도구 | 특징 | 한계 |
|------|------|------|
| **SuperMemo / Anki** | SM-2 알고리즘 적용 | 영어 단어 플래시카드 특화, 한국 대학 시험 부적합 |
| **Notion / 구글캘린더** | 범용 일정 관리 | 망각곡선 자동화 X, 복습 시점 수동 입력 |
| **에브리타임** | 한국 대학 시간표 특화 | 학습 효율 분석 기능 없음 |
| **포모도로 앱** | 집중 시간 측정 | 학습 데이터와 연동 안 됨 |

## 4. 프로젝트 내용 설명

### 가. 시스템 개요

- **플랫폼**: Windows 데스크탑 (WPF)
- **언어**: C#
- **프레임워크**: .NET 8.0 (LTS)
- **UI 라이브러리**: MaterialDesignThemes 5.x
- **차트 라이브러리**: LiveCharts2 (LiveChartsCore.SkiaSharpView.WPF)
- **데이터베이스**: SQLite + Entity Framework Core 8.0
- **개발 환경**: Visual Studio 2022 Community

### 나. 주요 기능 (7개 탭으로 구성)

#### ① 대시보드 (메인 화면)
- 4개 요약 카드: 학습 주제 수 / 오늘 복습 / 다가오는 시험 D-Day / 🔥 연속 학습 일수
- 차트 2개: 과목별 학습 주제 분포 / 향후 14일 복습 일정
- 카드 클릭 시 해당 탭으로 즉시 이동

#### ② 학습 주제 관리
- 학습 주제 등록 (과목, 단원, 학습일, 메모)
- 등록된 주제 목록 (정렬·검색·필터 가능)
- **검색**: 과목·단원·메모 키워드 (debounce 250ms)
- **과목 필터**: 드롭다운으로 특정 과목만 표시
- 행 더블클릭 → 편집 다이얼로그 / Delete 키 → 삭제

#### ③ 오늘의 복습 (자가평가)
- 복습 예정일이 오늘 이전인 항목만 표시
- 행 선택 후 0~5점 자가평가 → SM-2 알고리즘 자동 적용
- 평가 점수 색상 구분 (5,4: 초록 / 3: 주황 / 2,1,0: 빨강)

#### ④ 시험 D-Day
- 시험 등록 (과목, 시험명, 시험일)
- D-Day 자동 계산
- **시험 대비 복습 일정 생성**: 선택한 시험의 학습 주제를 시험일 기준으로 역산하여 분산 배치
- 시험 검색/필터 (학습 주제와 동일 패턴)

#### ⑤ 포모도로 타이머
- 3가지 모드: 집중 25분 / 짧은 휴식 5분 / 긴 휴식 15분
- 시작/일시정지/리셋 컨트롤
- 세션 완료 시 트레이 알림 + Windows 시스템 사운드
- **오늘 / 이번 주 누적 통계** (회수 + 분)
- 집중 세션은 JSON 파일에 자동 기록

#### ⑥ 월간 캘린더
- 7×6 그리드 (월요일 시작, 한국 관례)
- 셀별 마커: 📚 학습 등록 / 🔁 복습 예정 / 📝 시험
- 오늘 강조 (노란 배경 + 주황 테두리)
- 시험일 셀 전체 빨강 배경 강조
- 이전/오늘/다음 달 네비게이션

#### ⑦ 상세 통계
- 요약 카드 4개: 누적 주제 / 누적 복습 횟수 / 30일 내 복습 예정 / 약점 주제
- 차트 3개:
  - **월별 학습 추이** (최근 6개월 선 차트)
  - **요일별 학습 분포** (월~일 막대 차트)
  - **복습 진행도 분포** (0회/1회/2회/3회/4회+ 막대)
- **약점 단원 Top 5**: EaseFactor 낮은 순 (우선 복습 권장)

### 다. 부가 시스템

#### 시스템 트레이 통합
- 종 모양 아이콘이 작업표시줄 트레이에 상주
- 더블클릭 → 창 복원, 우클릭 → 메뉴 (열기/종료)
- 풍선 토스트 알림 (Windows 10/11)

#### 자동 알림 (백그라운드)
- 설정 다이얼로그에서 알림 시각 지정 (HH:MM, 5분 단위)
- DispatcherTimer 1분 간격 체크
- 설정 시각 도달 + 오늘 미알림 시 "오늘 복습할 항목 N건" 트레이 알림
- 하루 1회만 발송 (중복 방지)

#### 데이터 백업/복원
- JSON 형식으로 전체 데이터 내보내기
- 가져오기 시 "교체" / "추가" 모드 선택
- 학습 주제 + 시험 + 메타정보(버전, 시각) 포함

#### 다크모드
- 라이트/다크 토글 (PaletteHelper)
- 설정 영속화 (`settings.json`)
- 모든 MaterialDesign 컨트롤 자동 적용

#### 과목별 색상 코딩
- 과목명 → 해시 → MaterialDesign 12색 팔레트 매핑
- 모든 DataGrid 좌측 4px 컬러 띠
- 차트(과목별 분포) 막대마다 그 과목 색상

#### 키보드 단축키 (11개)
- `Ctrl+1~7`: 탭 전환
- `Ctrl+N`: 학습 주제 추가 (포커스)
- `Ctrl+E`: 시험 추가
- `Ctrl+F`: 검색
- `Ctrl+D`: 다크모드 토글
- `Ctrl+B`: 백업 / `Ctrl+I`: 가져오기 / `Ctrl+,`: 설정
- `F5`: 새로고침
- DataGrid: `Delete` 삭제, `F2`/더블클릭 편집

## 5. 최종 예상 결과물

### 가. 결과물 형태

실행 가능한 Windows 데스크탑 애플리케이션 (`StudyPlanner.exe`)
- 설치 없이 즉시 실행
- 한국어 인터페이스
- 라이트/다크 모드

### 나. 7개 화면 구성

1. 대시보드 (요약 카드 4 + 차트 2)
2. 학습 주제 (등록 폼 + 표 + 검색/필터)
3. 오늘의 복습 (자가평가)
4. 시험 D-Day (등록 + D-Day 표 + 일정 생성)
5. 포모도로 타이머 (3 모드 + 누적 통계)
6. 월간 캘린더 (학습/시험/복습 마커)
7. 상세 통계 (카드 4 + 차트 3 + 약점 Top 5)

### 다. 기대 효과

1. **학습 효율 향상**: 망각곡선 기반 자동 복습 → 시간 대비 학습 효과 극대화
2. **시험 대비 체계화**: D-Day 역산 → 벼락치기 → 분산 학습 유도
3. **학습 동기 유지**: 연속 학습 일수, 포모도로 통계로 시각화된 진척도
4. **개인화 인사이트**: 약점 단원·요일별 패턴·시간대 자동 분석
5. **학습 환경 통합**: 일정·복습·집중·통계를 한 도구에서

### 라. 발표 시연 시나리오 (5분)

1. **앱 실행** → 트레이 알림 "오늘 복습할 항목 N건"
2. **대시보드** → 카드 4개, 차트, 연속 학습 일수
3. **학습 주제** → Ctrl+N으로 빠른 등록, 색상 띠 확인
4. **오늘의 복습** → 자가평가 → SM-2 결과 팝업
5. **시험 D-Day** → 시험 등록 → 일정 생성 → 캘린더에 반영
6. **포모도로** → 모드 클릭 → 1초 시작 시연
7. **캘린더** → 월별 학습 패턴, 시험일 빨강 강조
8. **통계** → 약점 Top 5, 요일별 패턴
9. **다크모드 토글** → 전체 화면 변환
