## 슬라이드 3 — 이론적 배경 (망각곡선)

### 에빙하우스 망각곡선 (1885)

> 학습된 내용의 **약 67%가 24시간 이내에 잊혀진다**

R(t) = e^(-t/S)

- R: 기억 보존율
- t: 경과 시간
- S: 기억 안정성

→ 적절한 시점에 복습하면 S가 커져 망각 속도 ↓

**시각화**: 망각곡선 그래프 한 장 (붉은 선 = 복습 안 함, 초록 톱니 = 복습 시)

**스피킹**: "1885년 에빙하우스가 발견한 망각곡선 이론으로, 복습 안 하면 1주일에 거의 다 잊습니다. 하지만 적절한 시점에 복습하면 그만큼 오래 기억됩니다."

## 슬라이드 6 — 핵심 알고리즘 (SM-2)

### SuperMemo SM-2 알고리즘

자가평가 점수 q (0~5)에 따라:

```
if q >= 3 (성공):
    interval ← 1, 6, prev×EF 순으로 증가
    repetitionCount ← +1
else (실패):
    interval ← 1
    repetitionCount ← 0

EF ← EF + (0.1 - (5-q)(0.08 + (5-q)0.02))
EF ← max(EF, 1.3)
```

→ **잘 외운 건 띄엄띄엄, 못 외운 건 자주**

**스피킹**: "공식 자체는 단순하지만, '잘 외운 건 띄엄띄엄, 못 외운 건 자주'라는 망각곡선의 핵심을 정확히 구현합니다."

## 슬라이드 11 — 라이브 시연 (2~3분)

> 슬라이드 없이 실제 앱 시연

### 시연 흐름

1. 앱 실행 → 트레이 알림 "오늘 복습할 항목 N건"
2. 대시보드 → 카드 4개, 차트 2개
3. 카드 클릭 → 학습 주제 탭 자동 이동
4. Ctrl+N → 새 주제 빠른 등록 (Enter로 제출)
5. 오늘의 복습 → 자가평가 5점 → SM-2 결과 팝업
6. 시험 D-Day → 일정 생성 → 캘린더에 즉시 반영
7. 포모도로 → 5분 모드 → 시작 → 빨리 감기로 완료 시연
8. 통계 → 약점 Top 5, 요일별 분포
9. 🌙 클릭 → 전체 다크모드 전환
10. Ctrl+B → 백업 파일 생성 → 가져오기 시연

### 어필 포인트 (자주 받을 만한 질문)

| 예상 질문 | 답변 요지 |
|----------|----------|
| "노션이랑 뭐가 달라?" | 노션은 수동 입력, 본 도구는 SM-2 자동. 분산학습은 망각곡선 130년 검증 이론. |
| "Anki도 이미 SM-2 쓰지 않나?" | Anki는 영어 단어 플래시카드 특화. 한국 대학 시험(과목/단원/시험일 역산)에 부적합. |
| "데이터는 어디 저장?" | 100% 로컬 SQLite. 외부 서버 전송 없음. |
| "오프라인인데 왜 좋아?" | 인터넷 안 끊김, 회원가입 X, 개인정보 외부 노출 X. |
| "포모도로는 왜 통합?" | 학습 시간 자동 측정 → 데이터화 → 학습 시간 통계와 연동 가능. |
