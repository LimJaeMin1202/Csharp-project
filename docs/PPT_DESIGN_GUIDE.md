# PPT 제작 가이드

> 발표 슬라이드(12장)를 실제로 만들 때의 디자인 프로토콜.
> PowerPoint / Keynote / Google Slides 모두 적용 가능.

---

## 0. 사전 준비

### 권장 도구
- **PowerPoint** (가장 무난, 학교 환경 호환)
- Keynote (Mac이면 더 예쁨)
- Canva (디자인 자신 없으면 템플릿 활용)

### 슬라이드 비율
- **16:9** (와이드스크린) — 요즘 강의실 표준
- 4:3은 쓰지 말 것

---

## 1. 디자인 컨셉

> "차분하고 학문적이지만, 핵심 메시지는 강하게"

- 배경: **밝은 화이트** (또는 아주 옅은 회색 `#FAFAFA`)
- 강조: **인디고 + 핑크** (앱 컬러와 일치 → 발표→앱 전환 시 일관감)
- 본문: 검정 (`#212121`) — 순검정 아닌 살짝 회색 검정
- 보조 설명: 회색 (`#666`)
- 여백 넉넉히, 한 슬라이드당 핵심 메시지 1개

## 2. 색상 팔레트

본 앱의 MaterialDesign 팔레트를 그대로 사용 — 발표와 시연의 일관성.

| 용도 | 색상 | HEX |
|------|------|-----|
| 주 강조 (제목, 핵심 키워드) | 인디고 | `#3F51B5` |
| 보조 강조 (부제, 액션) | 핑크 | `#E91E63` |
| 긍정/성공 표시 | 티얼/그린 | `#009688` / `#4CAF50` |
| 경고/주의 | 오렌지 | `#FFA726` |
| 부정/위험 | 레드 | `#E53935` |
| 본문 텍스트 | 다크그레이 | `#212121` |
| 보조 텍스트 | 미드그레이 | `#666666` |
| 배경 | 화이트/오프화이트 | `#FFFFFF` / `#FAFAFA` |

### 사용 규칙
- 한 슬라이드에 **3색 이하** (배경+본문+강조 1색)
- 챕터 슬라이드는 **인디고 배경 + 흰 글씨**로 변화 주기
- 그래프는 본 앱 색상 그대로 가져오면 시연 시 시각 연결됨

## 4. 마스터 슬라이드 / 레이아웃 패턴

### A. 표지 슬라이드 (1번)
```
┌────────────────────────────────────────┐
│                                        │
│                                        │
│       망각곡선 학습 플래너                │
│       Forgetting Curve-based ...        │
│                                        │
│       " 잊어버리기 전에 알려주는           │
│         똑똑한 학습 도우미 "              │
│                                        │
│                                        │
│        [학과 / 학번 / 이름]              │
│        2026.06                          │
└────────────────────────────────────────┘
```
- 가운데 정렬
- 메인 제목 인디고
- 부제는 영문 작게 회색
- 슬로건은 이탤릭 또는 따옴표로 강조

### B. 챕터/섹션 슬라이드 (해당 시)
```
┌────────────────────────────────────────┐
│ 인디고 배경 (#3F51B5)                    │
│                                        │
│                                        │
│        01                              │  ← 큰 번호 (60pt+)
│        문제 정의                         │  ← 챕터명
│                                        │
│        Why this matters                 │  ← 부제 (영문)
│                                        │
│                                        │
└────────────────────────────────────────┘
```
- 시각적 호흡 / 발표 흐름 끊어주는 역할

### C. 본문 슬라이드 (대부분)
```
┌────────────────────────────────────────┐
│ ▎ 슬라이드 제목                          │  ← 좌측 인디고 세로 바 + 제목
│ ─────────────────────────────────       │
│                                        │
│   • 핵심 메시지 1                        │
│   • 핵심 메시지 2                        │
│   • 핵심 메시지 3                        │
│                                        │
│   [표 또는 시각 요소]                    │
│                                        │
│                              p.5/12     │  ← 우하단 페이지 표시
└────────────────────────────────────────┘
```
- 좌측 인디고 세로 바(5px) + 제목
- 가로 구분선 (얇게)
- 페이지 표시 우하단 (선택)

### D. 시각 자료 중심 슬라이드 (망각곡선, 시스템 구성 등)
```
┌────────────────────────────────────────┐
│ ▎ 슬라이드 제목                         │
│                                        │
│                                        │
│          [큰 그래프/다이어그램]           │
│                                        │
│                                        │
│   ── 한 줄 설명 (회색) ──                │
└────────────────────────────────────────┘
```
- 시각 요소가 70% 이상 차지
- 텍스트는 최소 (그림이 말하게)

### E. 마무리/감사 슬라이드
```

│                                        │
│                                        │
│              감사합니다.                 │
│                                        │

│                                        │
│                                        │
│                                        │
└────────────────────────────────────────┘
```

## 5. 슬라이드별 상세 가이드

### 슬라이드 1 — 표지
- **요소**: 메인 제목 / 영문 부제 / 슬로건 / 학과·학번·이름·날짜
- **이미지**: 우측 또는 배경에 **흐릿한 망각곡선 그래프** 워터마크 (선택)
- **포인트**: 첫 인상이라 깔끔하게. 텍스트만으로 충분

### 슬라이드 2 — 문제 정의
- **레이아웃**: 좌측 텍스트 + 우측 비교 표
- **시각 요소**:
  - 좌측: "한국 대학생 평균 4~6과목 동시 수강" 큰 글씨
  - 우측: 4행짜리 표 (도구 / 한계)
- **강조**: "언제 다시 복습?"이라는 질문은 **핑크색 큰 글씨**로
- **이미지**: 책상 위 쌓인 책 아이콘 (선택, 작게)

### 슬라이드 3 — 망각곡선 이론 ⭐ 핵심
- **레이아웃**: 가운데 큰 그래프 + 하단 짧은 설명
- **시각 요소**: **앱의 망각곡선 차트 스크린샷 활용**
  - 빨간 선(복습 X) + 초록 톱니(SM-2 복습) 두 곡선
- **수식**: `R(t) = e^(-t/S)` — 가운데 또는 우측에 깔끔하게
- **인용**: 좌측 작게 "에빙하우스 (1885)"
- **포인트**: "67%가 24시간 내 잊혀짐" 한 줄을 굵게

### 슬라이드 4 — 솔루션 개요 (차별점 5가지)
- **레이아웃**: 2×3 그리드 또는 세로 5줄
- **각 항목**:
  - ✅ 아이콘 + 키워드(굵게) + 한 줄 설명
- **시각 요소**: 항목마다 다른 강조색 (인디고·핑크·티얼·오렌지·그린)
- **예시 (2×3 그리드)**:
  ```
  [✅ SM-2 자동]  [✅ D-Day 역산]
  [✅ 오프라인]   [✅ 포모도로 통합]
  [✅ 인사이트]   (빈 칸 or 강조구문)
  ```

### 슬라이드 5 — 시스템 구성
- **레이아웃**: 상단 7개 탭 박스 + 하단 기술 스택 표
- **시각 요소**:
  - 상단: 7개 사각형 박스 (아이콘+탭명, 같은 크기)
  - 하단: 기술 스택 표 (C# / .NET 8.0 / WPF / SQLite / EF Core / MaterialDesign / LiveCharts2)
- **포인트**: 정보 밀도 높은 슬라이드 — 폰트 작아도 OK

### 슬라이드 6 — SM-2 알고리즘 ⭐ 차별점
- **레이아웃**: 좌측 의사코드 + 우측 한 줄 결론
- **시각 요소**:
  - 좌측: 의사코드 (D2Coding, 회색 배경 박스)
  - 우측: **"잘 외운 건 띄엄띄엄, 못 외운 건 자주"** 큰 글씨
- **강조**: q≥3, q<3 분기 색깔로 (초록/빨강)
- **포인트**: 알고리즘 자체보다 결론 메시지가 핵심

### 슬라이드 7 — 핵심 기능 1 (학습+복습)
- **레이아웃**: 좌측 스크린샷 1장 + 우측 핵심 메시지 3개
- **시각 요소**: 학습 주제 탭 + 오늘의 복습 탭 캡처 콜라주
- **강조**: 단축키 `Ctrl+N`을 흰 배경 회색 박스로 키 모양처럼

### 슬라이드 8 — 핵심 기능 2 (시험 D-Day)
- **레이아웃**: 상단 흐름 다이어그램 + 하단 결과 화면
- **시각 요소**:
  - 상단: `[시험 등록]` → `[D-Day 자동]` → `[일정 생성]` → `[캘린더 반영]` 화살표
  - 하단: 캘린더 뷰 캡처 (시험일 빨갛게 강조)
- **포인트**: "벼락치기 → 분산 학습"이 슬로건처럼

### 슬라이드 9 — 핵심 기능 3 (분석/시각화)
- **레이아웃**: 2×2 그리드 — 4개 화면 미니 캡처
- **시각 요소**:
  - 좌상: 연속 학습 일수 카드
  - 우상: 월별 학습 추이 차트
  - 좌하: 약점 단원 Top 5
  - 우하: 캘린더 화면
- **포인트**: 시각 정보로 가득 — 텍스트는 최소

### 슬라이드 10 — 부가 기능
- **레이아웃**: 아이콘 6~8개 그리드 (3열)
- **각 항목**: 아이콘 + 한 줄 설명
- **포인트**: "데스크탑 앱으로서의 완성도" 한 줄을 상단에

### 슬라이드 11 — 시연
- **레이아웃**: **거의 비어있음** — 큰 글씨로 "Live Demo" 한 단어
- **이미지**: 우측에 손가락 클릭 아이콘 또는 마우스 아이콘
- **포인트**: 슬라이드는 거의 안 보이게, 앱 윈도우 띄우고 발표
- **준비**: 발표 전에 시연용 백업 파일(`demo_backup.json`) 미리 가져오기로 데이터 채워두기

### 슬라이드 12 — 마무리
- **레이아웃**: 가운데 3줄 요약 + 하단 "감사합니다"
- **시각 요소**:
  - ✅ 망각곡선 + SM-2 적용
  - ✅ 한국 대학 시험 특화
  - ✅ 학습 환경 통합 도구
- **하단**: 향후 확장 항목 1줄 (모바일, AI 추천)

## 6. 시각 자료 만드는 법

### 망각곡선 그래프 (슬라이드 3)
- 앱 실행 → 대시보드 → **이전 망각곡선 차트가 없으므로** PowerPoint로 직접 그리기
- 방법:
  - 가로축: 0~30일
  - 세로축: 기억 보존율(%) 0~100
  - 빨간 곡선: y = 100 × e^(-x/3) (가파른 감소)
  - 초록 톱니: 1일, 6일, 15일, 30일에 100%로 점프 + 사이 감소
- 또는 **Google Sheets에서 차트 그려서 캡처**

### 시스템 구성 다이어그램 (슬라이드 5)
- PowerPoint **도형 → 사각형** 7개로 탭 박스
- 각 박스: 아이콘 + 텍스트 / 배경 흰색 / 테두리 인디고 1px
- 정렬 균등 분배

### 비교 표 (슬라이드 2, 4)
- PowerPoint 기본 표 사용
- 헤더 행: 인디고 배경 + 흰 글씨
- 짝수 행: 옅은 회색 배경 (zebra striping)
- ✅/❌는 큰 폰트 (24pt)

### 코드/의사코드 박스 (슬라이드 6)
- 텍스트 박스 → 배경 `#F5F5F5` 또는 다크 `#263238` + 흰 글씨
- 폰트 D2Coding 16~18pt
- 라운드 모서리 4px

### 스크린샷 (슬라이드 7~10)
1. 앱 실행 → 시연용 데이터 가져오기 (`docs/demo_backup.json`)
2. 각 탭 캡처:
   - 대시보드, 학습 주제, 오늘의 복습, 시험 D-Day, 포모도로, 캘린더, 통계
3. **Windows + Shift + S** (캡처 도구)로 영역 캡처
4. PPT에 붙여넣기 후:
   - 그림자 효과 (Outer Shadow, 흐림 8px)
   - 모서리 라운드 8px
5. 필요하면 화살표/원 강조 (PowerPoint 도형)

### 아이콘 (필수)
- **Material Icons** (https://fonts.google.com/icons)
- **Lucide** (https://lucide.dev/) — 깔끔
- 라이센스 OK, 자유 사용
- 인디고 색으로 통일

## 9. 출력 / 제출

### 발표용 (라이브)
- `.pptx` 그대로 사용
- 발표자 노트는 별도 모니터에 (PowerPoint 발표자 보기)
- USB + 클라우드(구글 드라이브) 백업 둘 다

### 제출용 (인쇄·업로드)
- **PDF로 변환** (PowerPoint → 파일 → 내보내기 → PDF/XPS)
- 파일명: `학번_이름_발표자료.pdf`
- 폰트 임베드 안 되면 화면 캡처 PDF로

### 백업
- 발표 30분 전: 슬라이드 PDF 1부 + 시연 백업 데이터 1부를 USB에
- 발표 직전: 노트북 시간 확인, 알림 OFF (Windows + A → 집중 모드)
