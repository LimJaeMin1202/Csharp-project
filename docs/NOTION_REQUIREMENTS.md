# 망각곡선 학습 플래너 — 요구사항 정리

## 핵심 기능

- 사용자는 학습 주제를 등록할 수 있다.
    - 필수 입력: 과목, 단원/주제
    - 선택 입력: 학습일(기본 오늘), 메모
    - 등록 즉시 SM-2 알고리즘의 초기값으로 저장됨 (RepetitionCount=0, EaseFactor=2.5)
    - 등록 후 다음 복습일은 학습일 당일로 자동 설정 (학습한 날 첫 복습 후보)

- 사용자는 등록한 학습 주제를 관리할 수 있다.
    - **검색**: 과목 / 단원 / 메모 키워드 (대소문자 무시, debounce 250ms)
    - **과목 필터**: 등록된 과목 목록에서 드롭다운 선택 (자동 갱신)
    - **정렬**: 컬럼 헤더 클릭으로 학습일/복습일/반복횟수 등 정렬
    - **편집**: 행 더블클릭 또는 F2 → 모달 다이얼로그
    - **삭제**: 휴지통 아이콘 클릭 또는 Delete 키 (확인 후)

- 사용자는 자가평가(0~5점)로 복습을 기록할 수 있다.
    - 점수 의미:
        - 5: 완벽하게 기억남
        - 4: 약간 머뭇거림
        - 3: 어렵게 기억함
        - 2: 가물가물 (실패)
        - 1: 거의 못함 (실패)
        - 0: 전혀 모름 (실패)
    - 3점 이상: SM-2 알고리즘으로 복습 간격 증가
    - 3점 미만: 복습 간격 리셋 (처음부터)
    - 자가평가 즉시 다음 복습일 자동 재계산

- 사용자는 시험을 등록하고 D-Day 계산할 수 있다.
    - 필수 입력: 과목, 시험일
    - 선택 입력: 시험명 (예: "중간고사", "기말고사", "퀴즈 3")
    - D-Day 자동 계산 (D-7, D-DAY, D+1 등)

- 사용자는 시험 대비 복습 일정을 자동 생성할 수 있다.
    - 등록된 시험 선택 후 [시험 대비 복습 일정 생성] 클릭
    - 시험일로부터 역산하여 해당 과목의 학습 주제 복습일 자동 분산 배치
    - 마지막 주제는 시험 하루 전, 그 앞은 이틀 전, … 순으로 배치

- 사용자는 포모도로 타이머로 집중 학습을 측정할 수 있다.
    - 3가지 모드: 집중 25분 / 짧은 휴식 5분 / 긴 휴식 15분
    - 모드 변경 시 타이머 즉시 리셋
    - 시작 / 일시정지 / 리셋 컨트롤
    - 집중 세션 완료 시:
        - 트레이 토스트 알림
        - Windows 시스템 사운드
        - JSON 파일에 세션 1건 자동 기록 (오늘/이번주 통계용)

- 사용자는 월간 캘린더로 학습 패턴을 한눈에 볼 수 있다.
    - 7×6 그리드 (월요일 시작, 한국 관례)
    - 셀별 자동 마커:
        - 📚 학습 등록한 날 (초록색 "N")
        - 🔁 복습 예정일 (파란색 "N")
        - 📝 시험일 (빨간색 과목명, 셀 전체 연빨강 배경)
    - 오늘 강조: 노란 배경 + 주황 테두리
    - 이전 / 오늘 / 다음 달 네비게이션

- 사용자는 학습 데이터를 백업·복원할 수 있다.
    - **내보내기**: 학습 주제 + 시험 + 메타정보(버전, 시각)를 JSON 파일로
    - **가져오기**: JSON 파일에서 복원
        - "교체" 모드: 기존 데이터 모두 삭제 후 가져오기
        - "추가" 모드: 기존 유지 + 새로 추가
    - 기본 파일명: `학습플래너_백업_yyyyMMdd_HHmmss.json`

- 사용자는 자동 알림을 받을 수 있다.
    - 설정 다이얼로그에서 활성화 + 시각(HH:MM, 5분 단위) 지정
    - 매분 백그라운드 체크 → 설정 시각 도달 + 오늘 미알림 → 트레이 토스트 알림
    - 알림 내용: "오늘 복습할 항목 N건"
    - 하루 1회만 발송 (중복 방지)

- 사용자는 다크모드를 사용할 수 있다.
    - 한 번 클릭으로 토글 (☀️/🌙 아이콘 변경)
    - 설정 영속화 → 앱 종료 후에도 마지막 모드 유지

## 메인 화면

### 상태 확인 (대시보드)

앱 시작 시 가장 먼저 보이는 화면.

- **요약 카드 4개** (가로 배치, 클릭 시 해당 탭으로 이동)
    - 🔵 학습 주제: N개 등록됨
    - 🟣 오늘 복습: N건 예정
    - 🟢 다가오는 시험: D-N (과목명)
    - 🟠 🔥 연속 학습: N일 연속! (오늘부터 거꾸로 매일 학습한 일수)

- **분석 차트 2개**
    - 과목별 학습 주제 분포 (막대, 과목마다 색상)
    - 향후 14일 복습 일정 (막대, 일별 복습 예정 수)

- **유틸리티 아이콘 (우하단)**
    - 📥 가져오기 / 📤 내보내기 / 🌙 테마 / ⚙️ 설정 / 🔔 알림

### 하단/측면 네비게이션 (탭 7개)

- **대시보드** (Ctrl+1)
    - 위 상태 확인 화면

- **학습 주제** (Ctrl+2)
    - 좌측: 학습 주제 등록 폼 (과목/단원/학습일/메모/등록)
    - 우측: 등록된 학습 주제 표
        - 좌측 컬러 띠 (과목별 색상)
        - 검색 박스 + 과목 필터 + 결과 카운트
        - 더블클릭 편집 / Delete 삭제

- **오늘의 복습** (Ctrl+3)
    - 좌측: 오늘 복습할 항목 표 (NextReviewDate <= 오늘)
    - 우측: 자가 평가 패널 (0~5점 버튼, 색상별로 구분)

- **시험 D-Day** (Ctrl+4)
    - 좌측: 시험 등록 폼 + 시험 대비 일정 생성 버튼
    - 우측: 등록된 시험 표 (D-Day 자동 계산, 검색/필터)

- **포모도로** (Ctrl+5)
    - 좌측: 큰 타이머 디스플레이 (96pt) + 모드 선택 + 컨트롤
    - 우측: 안내 + 오늘/이번주 누적 통계

- **캘린더** (Ctrl+6)
    - 월간 7×6 그리드
    - 학습/복습/시험 마커 + 오늘 강조
    - 이전/오늘/다음 달 네비게이션 + 하단 범례

- **통계** (Ctrl+7)
    - 요약 카드 4개 (누적 주제, 누적 복습, 30일 내 예정, 약점 주제)
    - 분석 차트 3개 (월별 추이, 요일별 분포, 복습 진행도)
    - 약점 단원 Top 5 (EaseFactor 낮은 순)

## 핵심 상태 추적 및 관리 (백엔드 로직)

### 1. 학습 주제 상태 (StudyTopic State)

각 학습 주제는 SM-2 알고리즘의 4가지 상태값으로 추적된다.

| 필드 | 의미 | 초기값 | 갱신 시점 |
|------|------|--------|----------|
| `RepetitionCount` | 성공한 복습 횟수 | 0 | 자가평가 3점 이상 시 +1, 미만 시 0 리셋 |
| `EaseFactor` | 난이도 계수 | 2.5 | 자가평가마다 공식에 따라 변동, 최저 1.3 |
| `IntervalDays` | 현재 복습 간격(일) | 0 | 자가평가 결과로 결정 (1일 → 6일 → 직전×EF) |
| `NextReviewDate` | 다음 복습 예정일 | 학습일 당일 | 오늘 + IntervalDays |

상태 전이:
```
[등록]
  ↓ (학습일 당일이 복습 후보)
[복습 대기]
  ↓ (자가평가 0~5점)
[복습 완료] → IntervalDays/RepetitionCount/EaseFactor/NextReviewDate 갱신
  ↓ (NextReviewDate 도달)
[다시 복습 대기]
```

### 2. SM-2 알고리즘 프로세스

```
자가평가 점수 q (0~5) 입력
  ↓
q >= 3 ? (성공)
  ├─ YES → 
  │       if RepetitionCount == 0: IntervalDays = 1
  │       elif RepetitionCount == 1: IntervalDays = 6
  │       else: IntervalDays = round(IntervalDays × EaseFactor)
  │       RepetitionCount += 1
  └─ NO  → 
          RepetitionCount = 0
          IntervalDays = 1
  ↓
EaseFactor = EaseFactor + (0.1 - (5-q) × (0.08 + (5-q) × 0.02))
EaseFactor = max(EaseFactor, 1.3)   # 하한선
  ↓
NextReviewDate = 오늘 + IntervalDays
```

### 3. 시험 D-Day 역산 프로세스

```
사용자: [시험 대비 복습 일정 생성] 클릭
  ↓
1. 선택한 Exam의 ExamDate 가져오기
2. 같은 Subject의 StudyTopic 목록 조회
3. daysUntil = (ExamDate - 오늘).Days 계산
  ↓
daysUntil <= 1 ?
  ├─ YES → 모든 주제 NextReviewDate = 오늘 (지금 바로 복습)
  └─ NO  → 
          window = daysUntil - 1   # 오늘 다음날 ~ 시험 전날
          for i in 0..topics.Count-1:
              offset = (i % window) + 1   # 1 ~ window
              topics[i].NextReviewDate = ExamDate - offset일
          # 결과: 시험 직전까지 분산 복습 배치
```

### 4. 자동 알림 상태 머신

```
설정값:
  - DailyNotificationEnabled (bool)
  - DailyNotificationTime ("HH:mm")
  - LastNotificationDate ("yyyy-MM-dd")

매 1분 (DispatcherTimer):
  if !DailyNotificationEnabled: return
  if LastNotificationDate == 오늘: return   # 이미 보냄
  if 현재시각 >= 설정시각:
      ShowNotification("오늘 복습할 항목 N건")
      LastNotificationDate = 오늘
      Save settings
```

### 5. 포모도로 세션 상태 머신

```
상태: Idle | Running | Paused | Completed

[Idle]
  ↓ 시작 클릭
[Running] (DispatcherTimer 1초 간격으로 remainingSeconds--)
  ├─ 일시정지 클릭 → [Paused] → 시작 클릭 → [Running]
  ├─ 리셋 클릭 → [Idle]
  └─ remainingSeconds == 0 → [Completed]
                                    ↓
                                  if 모드 == 집중:
                                    PomodoroLogService.RecordSession(분)
                                    트레이 알림 + 시스템 사운드
                                  타이머 리셋 → [Idle]
```

### 6. 데이터 갱신 전파

모든 데이터 변경 작업(등록/편집/삭제/자가평가/시험일정생성/import) 후 다음을 순차 갱신:

```
LoadTopics()      # 학습 주제 캐시 + 표 + 과목 필터 ComboBox
LoadReviewList()  # 오늘의 복습 표 + 카운트 + 빈 상태
LoadExams()       # 시험 캐시 + 표 + 시험 과목 필터
LoadDashboard()   # 카드 4개 + 과목별 차트 + 14일 일정
LoadStatistics()  # 통계 탭 카드 + 차트 3개 + 약점 Top 5
BuildCalendar()   # 월간 캘린더 셀 42칸 재생성
```

### 7. 데이터 저장 위치

| 데이터 | 위치 | 형식 |
|--------|------|------|
| 학습 주제 | `bin/Debug/net8.0-windows/studyplanner.db` | SQLite (EF Core) |
| 시험 | 같은 DB | SQLite |
| 앱 설정 | `bin/Debug/net8.0-windows/settings.json` | JSON |
| 포모도로 세션 | `bin/Debug/net8.0-windows/pomodoro.json` | JSON |
| 백업 파일 | 사용자 선택 위치 | JSON (`학습플래너_백업_*.json`) |

모든 데이터는 **로컬에만 저장**되며, 외부 서버로 전송되지 않는다.

## 비기능 요구사항

### 성능
- 검색 입력 debounce 250ms (빠른 타이핑 시 끊김 없음)
- 학습 주제 캐시 후 메모리 상에서 필터링 (DB 재쿼리 최소화)
- 캘린더 빌드는 한 달치(42칸) DB 1회 조회

### UX
- 키보드 단축키 11개 이상 (마우스 없이 핵심 작업 가능)
- 모든 다이얼로그 첫 필드 자동 포커스 + Enter 저장 + Esc 취소
- 빈 상태 안내 메시지 (학습 주제 0개 등)
- 다크모드 영속화 (설정 기억)

### 안정성
- 백업 파일 손상 시 에러 메시지 (앱 크래시 X)
- 잘못된 입력 검증 (필수 필드 비어있으면 알림)
- 트레이 아이콘 종료 시 자원 정리

### 호환성
- Windows 10/11 (.NET 8.0 Desktop Runtime)
- 한국어 폰트(맑은 고딕) 기본, 영어 폰트 fallback
